## Core guidance from the expanded handbook

*Image generation and image editing*

### Where this tool earns its place

Google positions Nano Banana 2 for rapid iteration and instruction following, and Nano Banana Pro for demanding fidelity tasks. The model may be available through Gemini or supported developer experiences; check the chosen product.

### Before the first prompt

Provide an approved visual reference plus a one paragraph explanation of what the image must communicate. Assign each reference a role: subject identity, lighting, palette or composition. Do not treat all images as interchangeable instructions. Ask for one change at a time.

### A complete business exercise

For a series of five workshop photographs, establish the approved object and surface. Produce one overview, then a close detail, a demonstration angle, a person interacting with the real object where consent permits, and a final contextual image. Compare consistency in a contact sheet. Replace inaccurate visuals with genuine source photography.

### Copy ready prompt for this tool

> Use reference image one only for the colour and shape of the approved ceramic cup. Use reference image two only for soft window lighting. Create a realistic close detail of the cup’s handle on a worn timber table. Keep the handle, lip and glaze appearance consistent with reference one. Focus on the small variation in the ceramic surface. No text, extra handles, glowing rim, impossible reflections or distorted hands.

### When the result is weak

If the references cause confusion, explicitly assign their purpose and remove irrelevant ones. If the generator changes the product silhouette, switch to compositing the real photograph rather than accepting an inaccurate depiction.

### Human editorial finish

Avoid making five images identical except for their zoom level. Give each a reason to exist: shape, scale, use, texture, context.

### Approval boundary and common errors

Check the exact model selected and regional access; do not confuse a photorealistic result with proof of an actual product.

## First session: from a blank workspace to a reviewable result

1. Define what stays constant across the series: object geometry, wardrobe, surface, palette and lighting.
2. Choose a small collection of authorised references; assign each a named role.
3. Generate the hero image first and record the accepted result.
4. Request one change per variation, such as camera angle or crop, while repeating preservation rules.
5. Compare all frames side by side for object drift, inconsistent textures or changing details.
6. Reject unsuitable variations and composite original photographs where product fidelity is essential.

## Prompt ladder: simple, evidence based and advanced

The prompts below are teaching examples. Replace fictional context with approved records. A tool that does not support freeform prompting may require you to perform the equivalent steps through its own interface.

### First pass

```text
Describe the stable details visible in reference one. Separate reliable observations from uncertain guesses.
```

### Image instruction

```text
Use reference one for the shape and colour of this ceramic vessel; reference two only for morning window light. Make a close view of the handle on the same timber table. Do not change the vessel.
```

### Series review

```text
Compare these five frames for consistency in handle shape, glaze, shadow direction and visual weight. Flag the specific frame and region of any defect.
```

## What an acceptable result looks like

A usable five image set should show different information: overall shape, surface, size, method of use and setting. Five identical crops are not a rich campaign.

## If the first version disappoints

When references compete, remove one or spell out which governs shape and which governs mood. Retain the original object photo for any claim about materials or proportions.

## Human editorial finish

Give each image a real reason to exist in the buyer journey. Replace the “perfect” scene with one that answers an actual customer question.

## Practice assignment

Using a fictional or appropriately protected version of the case, complete **maintain visual consistency across image variations**. Save an evidence inventory, the first draft, a precise correction request and the reviewed deliverable. Write a short comparison showing what the revision genuinely improved.

## Approval and success test

Is the subject consistent, and do synthetic scenes avoid impersonating the real shop or staff?

## Reference lab: maintaining a visual subject across a campaign

Nano Banana is a name used for Google's image generation and editing systems. The correct model and controls depend on the Google product and account. The useful skill is assigning jobs to references. One picture may establish the actual product, another the lighting direction, and a third the approved palette. Blending them without roles can cause the model to invent a hybrid object.

```text
Image A is the actual ceramic mug, and it controls the product's exact
shape, handle, glaze colour and printed mark. Image B shows only the
lighting style: soft overcast window light. Image C is only a palette
reference: cream, olive and warm brown. Create a lifestyle photograph
of the mug on a breakfast table, 4:5 crop, with a real wooden surface,
one folded cloth and natural contact shadows. Do not copy objects from
B or C, change the mug's design, add extra printed text or produce a
human face. Leave the left third relatively quiet for a headline.
```

**Compare results across three images.** Do not approve a set because each frame is attractive in isolation. Verify that handle shape, scale, surface finish and branding remain consistent. Compare with the reference in a split screen. If the item mutates, stop generating it as the source of truth and composite the actual photographed product into the desired scene.

**Translation and embedded text.** Even if the image model renders words relatively well, an important price or date must be checked and should normally be added through an editable layer. If the image contains a location cue, confirm that it is genuinely appropriate rather than an invented local landmark.

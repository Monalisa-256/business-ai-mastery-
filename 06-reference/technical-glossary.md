# Practical glossary for business owners and content makers

The purpose of these definitions is to make tools easier to operate, not to make basic work sound complicated. Product interfaces and model architecture change, so read each term in context.

| Term | Practical meaning | Why it matters |
| --- | --- | --- |
| Model | The underlying system that generates or analyses content | A model and the app exposing it are different |
| Application | The workspace a person uses | Controls, permissions and exports depend on it |
| Prompt | The request and its relevant context | Unclear requests produce plausible but unsuitable results |
| System instructions | Higher-level directions controlling an assistant | Untrusted customer text cannot override them |
| Context window | The material a model can consider in a task | Large projects need careful source selection |
| Retrieval | Pulling relevant text or records into a response | Retrieved data may still be stale or incomplete |
| Grounding | Tying an answer to supplied or retrieved evidence | Improves traceability, not automatic truth |
| Hallucination | A plausible but unsupported or incorrect output | Requires independent checking |
| Multimodal | Working across text, images, audio and video | Each medium needs different quality checks |
| Text to image | Creating an image from a description | Good for concepts, not inherently factual product photos |
| Image to video | Animating or interpreting an image as moving footage | Motion may alter object identity |
| Text to speech | Producing narration from written text | Requires consent, pronunciation and listening checks |
| Reference image | An image guiding part of a visual result | Its allowed role must be specified |
| Storyboard | Sequence of planned shots | Prevents random, disconnected video clips |
| Keyframe | Specific frame used to guide animation or editing | Helps control start or end of movement |
| Colour grading | Adjusting the look of video | Should not misrepresent product colour |
| Safe area | Region where text remains visible on a platform | Prevents obscured captions and CTAs |
| Alt text | Text describing an image's informative content | Helps people who cannot see the image |
| Consent | Permission for a defined use of someone's data or media | Needed before many identifiable voice or image uses |
| Content Credentials | Provenance information associated with media | Useful, but not proof every depicted claim is true |
| CRM | System for managing customer relationships | Needs clean records and privacy controls |
| ERP | System for coordinating business resources | Automation must respect source-of-truth records |
| SKU | Stock keeping unit | Prevents confusion between similar product variants |
| Gross margin | Gross profit relative to revenue under an accounting definition | Not equal to cash received |
| Cash flow | Money moving into and out of an organisation | Different from accounting profit |
| Conversion rate | Share of a defined base completing a specified action | Denominator must be explicit |
| Attribution | A method of assigning credit to marketing activities | Results are estimates influenced by tracking conditions |
| Automation trigger | Event that starts a workflow | Must be precise to prevent duplicate action |
| Human approval | Authorised person checks and accepts an action | Essential for sensitive, irreversible decisions |
| Idempotency | Preventing duplicate effects when an operation repeats | Useful for payments, messages and record updates |
| Prompt injection | Instructions embedded in untrusted material | Can redirect connected assistants if not contained |
| Benchmark | Controlled test of model capability | Does not guarantee fit for your business case |
| A/B test | Comparison of controlled variants | Requires consistent conditions and appropriate measurement |

## A useful habit

When a term appears in a vendor guide, ask what **input**, **output**, **control** and **evidence** it represents in your actual workflow. If a term cannot be connected to a practical action, it probably does not belong in a beginner lesson.

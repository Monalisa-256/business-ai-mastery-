## Updating a chapter

1. Open the provider's official current documentation.
2. Note the retrieval date and distinguish an API model from a feature in a consumer application.
3. Check country, plan, device, account role and credit requirements where relevant.
4. Revise the lesson with an independently reproducible example.
5. Review every relative image and navigation link.
6. Change the update note in this file and describe what was changed in the contribution.

Do not claim a tool performed an action merely because a demonstration prompt describes the action. Examples are educational; interface capabilities must be verified in the user's actual account.

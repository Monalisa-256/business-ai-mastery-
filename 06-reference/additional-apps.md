# Further tools from the original field guide

These are additional applications named in the earlier field guide. They supplement the 27 primary chapters; they are not all model families. Each entry has a practical task and an official starting point.

### NotebookLM for source based learning

Place related source documents into one notebook. Ask a question that each source can answer, then inspect the cited passage. Its generated audio or visual overviews are study aids, not recordings of original speakers. A useful task is to turn approved training policies into a staff FAQ, with every answer mapped to a named policy section. [Official NotebookLM Help](https://support.google.com/notebooklm/)

### Adobe Express for smaller design jobs

Use a brand template to assemble an editable flyer or a short social graphic. Replace stock text with the business's approved copy and verify the actual logo, image crop and mobile readability. Prefer a clear visual hierarchy over one click effects. [Adobe Express support](https://helpx.adobe.com/express.html)

### Pika for short visual experiments

Use a single reference frame and a narrowly described movement. Keep duration short when testing. Check the first and last frames for changes in the subject and assemble the selected clip in an editor. Feature names and access vary. [Pika](https://pika.art/)

### Adobe Podcast and Audacity for speech repair

Adobe Podcast can improve recorded speech, while Audacity provides detailed manual sound editing. Record in a quiet place, retain the original, remove only distracting noise, adjust loudness and listen to the results. Aggressive repair can make consonants strange or remove a speaker's character. [Adobe Podcast](https://podcast.adobe.com/) and [Audacity manual](https://manual.audacityteam.org/)

### Gamma and PowerPoint for presentations

Start with one message per slide, factual figures, and an audience question. Use generated outlines to plan the argument, then edit the actual slide objects. Presentations should not replace supporting evidence with decorative imagery. PowerPoint works within an existing Microsoft workflow; Gamma can speed up initial layout. [Microsoft PowerPoint](https://support.microsoft.com/powerpoint) and [Gamma help](https://help.gamma.app/)

### Metricool for content measurement

Connect approved channels and record the meaning of each metric. Compare posts that had a similar goal and distribution. Do not confuse impressions, views, enquiries and purchases. Use observed differences to design a small test the following month. [Metricool help](https://help.metricool.com/)

### Google Drive and OneDrive for version control

Create Source, Working, Review and Approved folders. Retain original media and the approved wording. Use meaningful file names and access controls. Connected assistants should receive the approved version, not every abandoned draft. [Google Drive](https://support.google.com/drive/) and [OneDrive](https://support.microsoft.com/onedrive)


## When to add a supplementary tool

A new tool should resolve a demonstrated gap: source study, editable social layout, noise reduction, presentation delivery, measurement or file organisation. Do not buy it merely because it appears on a list. The first task should have a testable improvement and an owner.


## Expanded companion lessons

The first edition mentioned several practical apps only in passing. This edition now includes dedicated Markdown chapters for:

* [Gemini Notebook](../02-business-management/gemini-notebook.md), for reading source collections and tracing citations.
* [Adobe Express](../03-content-creation/adobe-express.md), for editable social graphics and brand adaptation.
* [Adobe Podcast](../03-content-creation/adobe-podcast.md), for recorded speech cleanup and multitrack audio work.
* [Audacity](../03-content-creation/audacity.md), for detailed listening, trimming and loudness correction.
* [Gamma](../03-content-creation/gamma.md), for presentations whose structure must follow verified evidence.
* [Metricool](../03-content-creation/metricool.md), for scheduling and results interpretation.

These tools are companions, not mandatory purchases. A basic phone camera, reliable spreadsheet and existing customer system can be more valuable than adding another subscription. Begin with the actual problem and compare how long it takes to produce a reviewed, usable result.

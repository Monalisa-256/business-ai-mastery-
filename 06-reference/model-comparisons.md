# Compare tools by job, not hype

![Management decision flow](../assets/illustrations/management-review.svg)

A business application is not a model. Some models are used through several applications, and some applications route tasks between models without displaying the choice. Model names and plans change. Use the software that can safely reach the correct evidence and produce an editable, reviewable result.

## How to choose

Write the task, authoritative input, cost, privacy constraint, delivery format and reviewer. Trial one real job with a small safe sample. Measure time to an **approved** result rather than time to a first draft. Two subscriptions that solve the same problem may be less valuable than fixing the source records.

## Model names versus access

As of 20 November 2026, official providers document GPT 6.2 Astra and Sol, Claude Opus and Sonnet 5.5, Gemini 4 Carbon, GPT Image 2.6 and other specialist models used in this course. An API launch does not guarantee that a named model is present in every application, account, region or plan. Check current documentation and your interface.

## A decision tree in words

1. **Is there a live operational record that must be changed?** Begin in the system of record and verify whether its own approved assistant supports the task. Use an authorised human approval before write actions.
2. **Is the job to understand documents and explain a decision?** Begin with a capable general model or a source-grounded notebook. Supply a clear authoritative source pack and verify the citations.
3. **Is the output a public image of a real sellable product?** Photograph the real product. Use image generation for exploratory concepts, backgrounds or appropriately disclosed illustrations.
4. **Is the output a video proving what happened?** Record it. Use generated video for conceptual inserts when appropriate, not as documentary proof.
5. **Does the output need a specific natural voice?** Prefer a consenting human recording where practical; use licensed synthetic speech if the audience and disclosure requirements permit it.
6. **Does a person need to publish or send the result?** Keep an approval, provenance and revision record.

### The model-versus-product trap

OpenAI's GPT 6.2 Astra and Sol API model options, Claude Opus and Sonnet 5.5, Gemini 4 Carbon and Neon, GPT Image 2.6, Midjourney V8.2 and Ideogram 4.6 serve different functions. A consumer app may hide the underlying model or route requests automatically. A provider's announced feature does not establish access on a Free plan, in a particular country, or in a connected enterprise workspace. Teach the visible user workflow, then document the underlying model when verifiable.

### Trial checklist

Run three real but appropriately protected tasks: an easy normal case, a messy case with missing fields, and a case that should stop for human approval. Record the time to a correct approved result, number of edits needed, source accuracy, file export quality and cost. Choose the tool that handles your actual business constraints. Avoid paying for overlapping subscriptions purely because two brands appear in rankings.
